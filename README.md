# MY WORKSPACE 2.0 — 행정업무 지식관리 + 개인 일정

원노트 업무일지를 대신할 개인용 웹앱입니다. 설치·빌드 없이 브라우저(Chrome, Edge)에서 바로 실행됩니다.
HTML5 · CSS3 · Vanilla JavaScript만 사용했습니다(프레임워크·외부 라이브러리 없음).

## 실행 방법
1. `my-workspace` 폴더의 **`index.html`을 더블클릭**합니다(Edge 또는 Chrome).
2. 왼쪽 메뉴 **가져오기** → 「가상의 샘플 데이터로 체험」으로 먼저 살펴볼 수 있습니다.
3. 실제 자료는 **가져오기**에서 `onenote_blocks_masked.json`, `work_items_by_category.csv`를 선택 → 「검사하기」 → 확인란 체크 → 「이 기기에 저장」.

자료는 **그 PC의 그 브라우저 안**에만 저장됩니다. 다른 PC·휴대폰과 자동으로 맞춰지지 않습니다.
브라우저 기록을 지우거나 PC를 바꾸기 전에 **설정 → 백업 파일 내보내기**를 해 두세요.

## 편집기 사용법
- 블록 위 도구 막대의 버튼으로 블록을 추가합니다.
- 줄 맨 앞에 `# ` `## ` `- ` `1. ` `[] ` `> ` 를 입력하면 제목·소제목·글머리표·번호·체크박스·인용으로 바뀝니다.
- Enter: 새 블록, Shift+Enter: 블록 안 줄바꿈, 빈 목록에서 Enter: 목록 끝내기.
- 블록 왼쪽 ⋮ : 종류 바꾸기, 위·아래 이동, 복제, 삭제.
- 입력을 멈추면 0.7초 뒤 자동으로 저장됩니다. 저장에 실패하면 화면 위쪽에 경고가 표시됩니다.

## 개인 일정과 갤럭시 알림
- 개인 일정은 업무 자료와 **다른 저장소**(`my-workspace-personal`)에 저장되고, 백업 파일도 따로 만듭니다.
- 휴대폰 알림은 「개인 일정 → 휴대폰으로 보내기」에서 ICS 파일을 만들어 **휴대폰에서 삼성 캘린더로 가져와야** 등록됩니다. 파일을 만드는 것만으로는 등록되지 않습니다.
- 휴대폰에서 쓰려면 앱 화면 파일을 https 주소에 올려야 합니다. 자세한 순서와 실기기 검증 목록: `docs/galaxy-guide.md`
- 행정 PC에서는 Google 연결을 하지 않으며, 행정 PC에서 만든 파일을 휴대폰으로 옮기기 전에는 기관 보안정책 확인을 요구합니다.

## 보안 유의사항
- IndexedDB(브라우저 저장소)는 암호화된 보안 저장소가 아닙니다.
- 가림 처리된 파일에도 민원인 이름·연락처·주소·내부 업무 정보가 남아 있습니다.
- 실제 자료(JSON·CSV·백업 파일)는 이 폴더 **밖**에 두고, GitHub 등 공개 저장소에 올리지 마세요(`.gitignore`에 차단 목록 있음).
- 서비스 워커는 앱 화면 파일만 캐시하며 자료 파일은 캐시하지 않습니다.
- 앱 화면에는 보안 정책(CSP)이 걸려 있어 외부 주소로 자료를 보내는 요청을 브라우저가 차단합니다.
- 이 앱은 어떤 자료도 외부로 전송하지 않습니다. (국가법령정보센터·링크 블록은 사용자가 눌렀을 때 새 창으로 열립니다)
